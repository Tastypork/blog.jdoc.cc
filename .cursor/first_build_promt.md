# Build a New Client Website

Use the project's existing `.cursor` rules and relevant skills.

## 1. Understand the project
- Read `docs/client-brief.md` if it exists.
- Read `docs/requirements.md`
- Inspect the repository, package.json, Astro configuration, existing components, styling, and assets.
- If the client brief is missing, use the new-site-discovery skill to gather requirements.
- Identify missing information and distinguish facts from assumptions.

## 2. Plan the website
- Define the target audience, primary conversion goal, sitemap, and page sections.
- Use the design-direction skill to establish a distinctive visual direction.
- Identify required content, imagery, components, and functionality.
- Present the plan and important assumptions before major implementation.
- We build beautiful and high quality premium websites. Design decisions should reflect this.

## 3. Implement
- Build with Astro, TypeScript, and the project's existing CSS conventions.
- Prioritize responsive layouts, strong visual hierarchy, polished typography, purposeful imagery, and clear calls to action.
- Reuse components where appropriate without making every page look identical.
- Follow accessibility, performance, SEO, and security standards.
- Do not invent client facts, testimonials, credentials, or business results.

## 4. Refine and verify
- Use the polish-marketing-page skill to improve the visual result.
- Use the project-scaffold command to standardize README.md and .gitignore.
- Use the og-meta-optimizer skill to verify social-sharing metadata.
- Use the builder-attribution skill if client requirements permit a Jocal credit.
- Run available build checks and use Playwright for browser testing when configured.
- Report remaining issues rather than claiming unverified success.

## 5. Deliver
Summarize the pages and features implemented, important files changed, checks performed, assumptions, and anything requiring approval.

Do not deploy, purchase services, expose secrets, or make destructive changes without my permission.
