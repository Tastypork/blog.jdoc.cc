# Polish a marketing page

1. Inspect the page and shared components; identify the page's audience and primary conversion action.
2. Evaluate the first viewport, hierarchy, typography, spacing, color consistency, imagery, section rhythm, CTA clarity, mobile layout, accessibility, and trust signals.
3. Report the five highest-impact issues, ordered by impact and effort. Distinguish observed problems from subjective design opportunities.
4. Implement focused changes using existing tokens and components. Avoid a full rewrite unless requested.
5. Do not use em dashes (—) in headings, body copy, or UI text. Use a period, comma, colon, or parentheses instead.
6. Avoid generic AI styling: use a deliberate art direction that matches the brand and audience.
7. Verify at mobile and desktop sizes, check keyboard focus and reduced motion, and run available project checks.
8. Summarize what changed and any remaining design decisions that need user/client input.
